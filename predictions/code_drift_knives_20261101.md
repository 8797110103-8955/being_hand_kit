### K1 错在哪（这一格比其余五格值钱）

预测时的想法：mtime 的问题是「太灵敏」，touch 一下就报变，所以只有格 3 会红。
实测多红两格，暴露的是另一半——

- 格 1（改内容要指名）红：同一秒内写两次，mtime 不变 ⇒ **内容真变了也不报**。
- 格 6（读不到要留字）红：`chmod` 只改 ctime 不改 mtime ⇒ **权限变了完全看不见**。

所以 mtime 的形状是「**只在中间一小段上像指纹**」：内容变了且跨秒它看得见；
同一秒里变了、或只动元数据，它全瞎——而那正是需要它的时候。

错的性质不是押错格，是**拿一段成立的等价当成全称等价**。
